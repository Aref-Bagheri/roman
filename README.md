# روایت — نسخه‌ی فایل‌محور برای GitHub Pages

روایت یک برنامه‌ی فارسی و راست‌چین برای نوشتن و مدیریت رمان است. این نسخه به MySQL، Supabase، سرور یا حساب ابری داخل برنامه نیاز ندارد و مستقیماً روی GitHub Pages اجرا می‌شود.

## امکانات
- ویرایشگر متن غنی، ابزارهای قالب‌بندی، فصل‌ها، یادداشت‌ها، شخصیت‌ها، خط زمانی، برچسب‌ها و آمار نوشتن.
- ذخیره‌ی خودکار در حافظه‌ی مرورگر همین دستگاه.
- ذخیره‌ی تمام پروژه (متن فصل‌ها، یادداشت‌ها، شخصیت‌ها، رویدادها و تنظیمات) در **یک فایل متنی `riwayat-project.txt`** با ساختار JSON خوانا.
- واردکردن همان فایل متنی در دستگاه دیگر برای بازیابی کامل پروژه.
- خروجی TXT و Word-compatible برای رمان.
- ظاهر محدود به سفید یخی، آبی نفتی و نارنجی؛ طراحی واکنش‌گرا برای گوشی و رایانه.

## نکته‌ی مهم درباره انتقال بین دستگاه‌ها
GitHub Pages فقط فایل‌های ثابت سایت را میزبانی می‌کند و اجازه نمی‌دهد سایت بی‌واسطه فایل‌ها را روی سرور بنویسد. بنابراین برنامه ابتدا خودکار در مرورگر فعلی ذخیره می‌کند؛ برای انتقال به دستگاه دیگر:
1. روی دکمه‌ی ⇅ بالای صفحه بزن و گزینه‌ی ذخیره‌ی فایل را انتخاب کن (در پیام، «لغو» یعنی ذخیره).
2. فایل `riwayat-project.txt` را در iCloud Drive، Google Drive، OneDrive، فلش یا هر فضای فایل شخصی خودت قرار بده.
3. در دستگاه دیگر سایت را باز کن، روی ⇅ بزن و این بار «تأیید» را برای واردکردن فایل انتخاب کن.
4. بعد از نوشتن‌های جدید، دوباره فایل را خروجی بگیر تا نسخه‌ی جدید جایگزین قبلی شود.

این روش هیچ پایگاه‌داده‌ای ندارد؛ اما همگام‌سازی زنده و خودکار بین دو دستگاه بدون یک سرویس همگام‌سازی/سرور ممکن نیست. فایل متنی پروژه باید خودت بین دستگاه‌ها منتقل یا در فضای فایل همگام‌شونده نگه‌داری شود. پیش از واردکردن فایل، از نسخه‌ی فعلی خروجی بگیر؛ واردکردن، پروژه‌ی فعلی مرورگر را جایگزین می‌کند.

## انتشار روی GitHub Pages
1. فایل ZIP را استخراج کن.
2. محتویات پوشه را مستقیماً در ریشه‌ی repository قرار بده؛ `index.html` و `styles.css` باید کنار هم باشند.
3. در **Settings → Pages**، گزینه‌ی Deploy from a branch را انتخاب کن و `main` و `/(root)` را تنظیم کن.
4. پس از انتشار، سایت را باز کن. برای پاک‌کردن کش قدیمی، یک بار `Ctrl + Shift + R` بزن.

## فایل‌ها
- `index.html` — رابط سایت
- `styles.css` — طراحی و رنگ‌بندی
- `app.js` — ابزارهای نویسندگی و مدیریت فایل پروژه
- `sw.js` — کش آفلاین
- `manifest.webmanifest` و `icon.svg` — نصب‌پذیری و آیکن
